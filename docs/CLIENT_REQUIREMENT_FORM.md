Internal AI Processing Note

This form is the client requirement input layer for the
website_master reusable website template.

The AI should use the collected information to customize:

config/business.js → Business identity, contact details, location,
theme and business configuration.

content/siteContent.js → Client-facing website content.

Existing reusable components → Visual rendering and page
composition.

Existing routes → Website pages.

Master Template Rule: Client-specific requirements must not directly
modify the frozen master template architecture. If a requirement needs a
structural/component-level change, evaluate it separately as a future
master-template version rather than changing the frozen template for one
client.
